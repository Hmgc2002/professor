Os critérios

  • Leitor de arquivo (IASA §5.4.5): azimute ajustável · velocidade melhor que 0,3 % · wow e flutter ponderados < 0,1 % · 30 Hz–20 kHz +2/−3 dB · tipos I, II e IV.
  • Conversor A/D (IASA §2.4.1): gama dinâmica ≥ 115 dB · THD+N < −105 dB · ±0,1 dB de 20 Hz a 20 kHz.
  • Captura (IASA §2.2, §2.3, §2.7, §2.8): ≥ 48 kHz (96 para música) · ≥ 24 bits · WAV/BWF · nunca com perdas.
  • Níveis: linha doméstica −10 dBV (0,316 V) · profissional +4 dBu (1,228 V) · picos da captura entre −12 e −6 dBFS (convenção deste curso).
  • Azimute: atraso E−D = 0 · agudos de E+D no máximo · em cada lado de cada fita.
  • Wow e flutter: tom de 3150 Hz, ≥ 5 s, ponderado, com o detetor declarado.

Os comandos

python captura.py relatorio captura.wav     # pico, rms, teto, dc, fundo, zumbido
python captura.py azimute   captura.wav     # atraso E-D, angulo, agudos
python captura.py wow       tom.wav 3150    # velocidade, wow e flutter, pico de modulacao

python margens.py ler      fita.wav [canal] # descodifica e prova (canal: 0, 1 ou soma)
python margens.py piloto   fita.wav         # velocidade e wow pela cadeia inteira
python margens.py margens  fita.wav         # quanto estrago a captura ainda aguenta
python margens.py comparar a.tap b.tap      # duas capturas dao o mesmo?

python ensaio.py                            # fita de ensaio, para praticar sem maquina
