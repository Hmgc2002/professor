# Respostas

Aqui ficam as entregas, uma por ficheiro, com o nome `AAAA-MM-DD.md`.

Como se produz uma: no fim de cada lição, o botão **«Copiar as minhas respostas»** gera o Markdown
com as respostas abertas e o resultado do quiz. Cola-o num ficheiro aqui e corre:

```
/corrigir abstracts-e-resumos
```

🔴 **Este diretório é público.** Neste tópico os exercícios pedem que resumas textos reais — e o
texto de um PR, de um post-mortem ou de um design doc do teu trabalho **não pode vir para aqui**.
Usa textos públicos (PRs open source, post-mortems publicados, PEPs, RFCs) ou inventados. Se
praticaste num texto do trabalho, entrega só o que mudaste e porquê, sem o texto.

O site não tem backend e nenhuma sessão lê o `localStorage` do teu browser — este ficheiro é a
única forma de as respostas chegarem à correção.
